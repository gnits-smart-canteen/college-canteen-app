# GNITS Smart Canteen

A web-based canteen ordering and management system designed for GNITS students and canteen administrators.

## Features

### Student Portal

* Secure login and registration using ERP ID
* Browse menu by category
* Add items to cart
* Daily specials section
* Dine-In and Parcel order options
* Secure payment simulation
* Live order tracking
* Order history
* Food reviews and ratings

### Admin Portal

* Live order management
* Update order status (Placed, Preparing, Ready)
* Manage daily specials
* Analytics dashboard
* Revenue and order insights
* CSV export of order data

## Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Firebase Authentication
* Firebase Firestore
* Git & GitHub

### Student Pages

* **index.html** – Login and registration
* **menu.html** – Browse menu and add items to cart
* **specials.html** – View daily specials
* **track.html** – Track active orders
* **history.html** – View past orders
* **reviews.html** – Submit and view food reviews
* **payment.html** – Complete order payment
* **receipt.html** – Display order receipt

### Admin Pages

* **orders.html** – Manages live orders and updates status
* **specials.html** – Manages daily specials
* **dashboard.html** – View analytics and revenue insights
